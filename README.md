# 인수인계의 전설 · DLC 오락실

인수인계서 없이 첫 출근한 담당자가 전임자의 업무폴더와 결재문서를 탐색하는 모바일 2D 업무 체험 게임입니다. 기존 AIgame의 10개 단서, 5개 보고 질문, 문서 탐색 이야기를 이어갑니다.

## 이번 변경

- 휴대폰 세로 화면, 안전 영역, 터치 버튼, 키보드와 작은 화면을 고려한 레이아웃
- 복고 셀 애니로 통일한 통통하고 순한 신입, 밝은 아이보리 피부의 까칠한 청사관리팀장, 전임자 선배
- 첫 출근·자료 탐색·보고·전화·엔딩의 신규 일러스트와 인물별 표정 변화
- 눈 깜빡임과 긴장할 때 흐르는 땀방울, 짧은 표정 반응, 타이핑 대사, 선택형 효과음·진동
- 메신저의 전송→읽음→입력 중→답장, 대화 기록
- 전화 연결 대기, 통화 시간, 음성 파형, 대화 선택, 캐릭터 성별에 맞춘 한국어 음성 파일
- 같은 브라우저에서 진행 자동 저장·이어서 하기, 새로 시작 전 확인창
- 완료 후 경품 응모, 번호 중복 방지, 관리자 명단·검색·CSV·무작위 추첨·개별 삭제

## 운영 구조

GPT Sites에서 사이트 배포, 런타임 비밀값, 데이터베이스를 관리합니다. Vinext/React 프런트엔드와 Cloudflare Worker API, Sites에 연결된 D1을 사용합니다. Vercel과 Supabase의 SDK, 공개 키, 외부 저장 요청은 없습니다.

일반 방문자는 계정 없이 플레이합니다. 진행 화면·단서·답변·메신저 대화·통화 단계와 플레이 토큰을 브라우저의 localStorage에 자동 저장합니다. 새로고침하거나 재접속하면 첫 화면의 “이어서 하기”로 복원합니다. 같은 브라우저에서만 이어할 수 있으며 저장 공간 삭제 시 기록도 사라집니다. 새 플레이는 확인 후 서버에서 새 세션 생성에 성공했을 때 기록을 교체합니다. 응모 양식의 이름·소속·휴대전화와 개인정보 동의는 진행 기록에 저장하지 않습니다.

서버에는 토큰 해시와 시작/완료 시각, 최종 점수·등급·단서 수·힌트 수만 보관하며 진행 화면과 답변을 저장하지 않습니다. 이어하기 시 토큰으로 완료·응모 상태를 확인하여, 완료 요청 직후 페이지를 닫았더라도 결과를 일치시킵니다. 완료 요청을 다시 보내도 기존 채점 결과를 바꾸지 않습니다. 소리 설정도 브라우저에 유지됩니다.

`/admin`은 별도 관리자 로그인 화면입니다. 비밀번호는 Sites의 `ADMIN_PASSWORD` 비밀 환경변수로 설정합니다. 클라이언트나 저장소에 비밀번호를 넣지 않습니다. 관리자 세션은 HttpOnly·SameSite 쿠키와 8시간 만료로 보호합니다. 로그인 시도 제한, 서버 측 접근 검사, 추첨·삭제 관리 기록이 있습니다.

응모에는 이름, 소속, 휴대전화 번호, 동의 시각과 동의문 버전을 저장합니다. 한 전화번호와 한 플레이에 한 번 응모할 수 있습니다. 화면에서는 연락처를 기본적으로 가리고, CSV에는 전체 연락처가 포함됩니다. 추첨은 이미 당첨된 사람을 제외하며 결과를 한 SQL 문장으로 저장합니다. 운영 종료 후 관리자 화면에서 개인정보를 삭제하세요.

대화는 준비된 시나리오·키워드별 힌트입니다. 생성형 AI 대화나 실제 전화 연결은 아닙니다. 주인공·전임자·소방관은 남성 한국어 음성, 팀장은 여성 한국어 음성 MP3를 사용합니다. 기기의 기본 TTS 음성에 의존하지 않습니다. 소리를 켜야 재생하며, 브라우저에서 자동 재생을 막거나 파일 재생에 실패하면 “음성 다시 듣기” 버튼을 제공합니다. 생성 정보는 `public/audio/ko-v1/README.md`에 있습니다. 동작 줄이기 설정에서는 눈 깜빡임과 땀방울을 숨깁니다. 게임 문서는 업무 체험을 위해 재구성된 자료입니다.

## 개발

Node 24 권장. `pnpm-lock.yaml`을 기준으로 설치합니다.

```sh
pnpm install --frozen-lockfile
pnpm db:generate
pnpm dev
```

로컬 `.dev.vars`에 `ADMIN_PASSWORD`를 설정합니다. 이 파일은 Git에 포함되지 않습니다. D1 로컬 개발 환경에는 `drizzle/`의 마이그레이션을 적용해야 합니다. Sites는 배포에 포함된 마이그레이션으로 운영 DB를 준비합니다. `.openai/hosting.json`의 기존 프로젝트 ID와 D1 바인딩을 보존하세요.

검증:

```sh
node node_modules/typescript/bin/tsc --noEmit
node --experimental-strip-types tests/game-save.test.mjs
node --experimental-strip-types tests/server.test.mjs
pnpm build
```

서버 통합 검증은 운영 핸들러와 격리된 메모리 SQLite를 사용합니다. 실제 응모 데이터나 운영 DB는 건드리지 않습니다.

## 이전 배포와 데이터

이 버전부터 새 응모와 플레이 완료 요약을 Sites에 저장합니다. 과거 Supabase 응모 내역을 자동으로 가져오지 않았으며, 기존 Vercel 프로젝트와 Supabase 데이터는 삭제하지 않았습니다. 과거 자료가 있다면 별도 내보내기·검증 후 이관해야 합니다.

DLC 오락실의 게임 카드 및 QR 목적지는 이 게임의 Sites 공개 주소로 연결하세요. 이 저장소를 변경하는 것만으로 별도 오락실 포털의 링크가 바뀌지는 않습니다.

기존 Vercel Git 자동 배포는 `vercel.json`의 `git.deploymentEnabled: false`로 이 저장소의 새 버전에 대해 비활성화합니다. 이전 배포는 별도로 보존됩니다.
