# 복고 셀 애니 · 이미지 기준

사용자가 비교 초안 중 선택한 B 복고 셀 애니와, 팀장님의 피부를 한 톤 밝힌 최종 시안을 기준으로 적용함.

## 인물

- 주인공: 국토부 광수의 둥근 볼과 순한 눈매를 참고한 성인 신규 담당자. 짧은 가르마 검은 머리, 하늘색 셔츠, 남색 넥타이와 사원증. 평상시·당황·안도의 세 표정.
- 청사관리팀장 / 지방공업주사: 눈물의 여왕 김지원의 또렷한 눈매와 긴 흑발을 참고한 성인 여성. 차콜 재킷, 아이보리 블라우스, 사원증. 얼굴·귀·목·손을 밝은 중성 아이보리 피부로 통일. 평상시·의심·작은 미소의 세 표정.
- 전임자 선배: 안경과 가디건, 친근한 인상의 별도 성인 캐릭터. 주인공과 팀장님과 같은 선화와 셀 채색을 적용.

## 미술 기준

1990년대 말~2000년대 초 2D 셀 애니메이션의 얇은 어두운 펜선, 차분한 사무실 색감, 매트한 2단계 음영. 배경도 회색 파티션·서류철·업무 PC·유선전화가 있는 같은 작품의 공간으로 통일. 과한 광택·노란 역광·사진 같은 피부·3D 렌더링은 피함. 캐릭터의 얼굴·의상·비율은 표정과 장면이 달라도 유지함.

## 현재 에셋

모든 신규 에셋은 `public/art/retro-v5/`에 위치함.

| 파일 | 사용 위치 |
| --- | --- |
| hero-expressions.webp | 내 생각, 프롤로그, 단서 발견, 보고 반응 |
| boss-expressions.webp | 프롤로그, 보고 질문과 답변, 데스크톱 인물 소개 |
| senior.webp | 메신저와 전임자 통화 |
| office.webp | 게임 공통 사무실 배경과 보고 장면 |
| arrival.webp | 시작 화면, 업무 지시, 보고 확인과 팀장 호출 |
| investigation.webp | 첫 출근, 단서함, 보고 결과 |
| phone.webp | 마지막 전화 수신 및 통화 |
| ending.webp | 보고 결과, 엔딩, 응모 안내와 완료 |
| arrival-blink.webp | 첫 화면·업무 지시의 두 인물 눈 깜빡임 |
| investigation-blink.webp | 첫 출근·자료 탐색 장면의 눈 깜빡임 |

표정 시트는 왼쪽부터 평상시·당황/의심·미소의 3열 구조. 배경 투명도를 유지하고 CSS로 필요한 셀을 표시함. 각 이미지의 실제 크기와 생성 정보는 같은 폴더의 `art-manifest.json`을 참고함.

## 생성 및 웹 적용

기본 imagegen 도구 사용. 확정 시안을 인물과 그림체의 공통 참조로 입력함. 장면에는 대사·제목·문서 정답을 그려 넣지 않고, 한국어 대사와 UI는 HTML로 표시함. 사용한 공통 지시: 얇은 손그림 선화, 동일 인물/의상, 매트한 셀 음영, 차분한 사무실, 팀장님은 밝은 중성 아이보리 피부. 사진 원본은 저장소에 포함하지 않음.

표정 시트와 전임자는 투명 배경으로, 나머지는 불투명 장면으로 생성함. WebP 변환은 파일 용량과 해상도 최적화만 수행함. 첫 화면의 장면은 우선 로딩, 후속 장면은 필요할 때 로딩함. 이미지 크기를 미리 지정해 레이아웃 변화를 줄이고, 문서·선택지·동의문 가독성을 유지함. 인물에는 짧은 반복 움직임과 표정 반응을 적용하며 움직임 줄이기 설정을 존중함.

기존 v4 이미지는 과거 자료로 보존하지만 현재 게임에서 참조하지 않음. 실제 인물의 참여나 보증을 의미하지 않는 게임 캐릭터임.


## 짧은 생활 반응

기존 표정 시트는 그대로 표시하고 `retro-v5/*-blink.webp`를 동일한 크기로 겹쳐 눈 영역만 짧게 노출합니다. 작은 초상의 주인공은 3.4초, 팀장은 3.8초 간격으로 한 번씩 깜빡이며 눈 감는 시간은 약 0.17~0.19초입니다. 긴장 표정의 연속 두 번 깜빡임은 제거했습니다. 몸은 3~4초 주기로 작은 기울임·들썩임을 반복하며, 이동 폭을 이전보다 줄였습니다. 긴장한 주인공의 청록색 땀방울 두 개는 2.1초 주기로 시간차를 두고 흐릅니다.

첫 화면과 프롤로그의 큰 그림에도 별도로 생성한 눈 감은 프레임을 적용합니다. 원본 1280×720 좌표계의 눈 두 곳만 SVG로 잘라 겹치며, 기본 그림과 같은 중앙 기준 cover 배치를 사용해 좁은 화면에서도 정렬을 유지합니다. 큰 그림의 주인공은 3.6초, 팀장은 4.2초 주기로 각각 0.18초·0.21초 동안 눈을 감습니다. 시작 지연도 0.2초·0.85초로 달리해 서로 다른 박자로 깜빡입니다. 그림 전체의 확대·이동은 제거했습니다. 원본 피부·옷·실루엣이 바뀌지 않도록 전체 프레임 교체를 피하고, 동작 줄이기 설정에서는 모든 몸 움직임·깜빡임·땀 효과를 끕니다. 편집 프롬프트와 영역은 같은 폴더의 `blink-manifest.json`, `arrival-blink-manifest.json`, `investigation-blink-manifest.json`에 기록했습니다.
