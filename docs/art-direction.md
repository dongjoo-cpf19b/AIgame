# 캐릭터와 화면

## 주인공

성인 신입 공무원. 둥근 얼굴과 볼살, 순한 눈매, 살짝 멍한 인상. 짧은 검은 머리, 흰 셔츠, 느슨한 넥타이, 파란 사원증. 평상시·당황·안도한 웃음의 세 표정. 사용자가 제공한 참고 사진의 친근한 인상에서 착안한 2D 캐릭터입니다. 사용자 제공 사진 원본은 저장소에 포함하지 않습니다.

## 여팀장님

청사관리팀장 / 지방공업주사인 성인 여성 캐릭터. 사용자가 제공한 김지원 사진의 눈매·옆가르마 긴 머리를 가볍게 참고하고, 주인공과 같은 선화·간결한 셀 채색·귀여운 얼굴 비율로 맞춘 2D 표현입니다. 남색 재킷과 아이보리 블라우스, 파란 사원증을 유지합니다. 평상시·까칠한 반응·작게 웃는 반응을 구분합니다. 실제 인물의 참여나 보증을 의미하지 않는 게임 캐릭터입니다.

## 공통 이미지 생성 지시

따뜻한 빛과 선명한 선화, 부드러운 2D 애니메이션 셀 채색. 성인 사무직 캐릭터. 정사각형 셀로 정렬한 상반신 스프라이트. 표정 간 캐릭터 일관성 유지. 머리와 팔이 옆 셀로 넘어가지 않도록 여백 확보. 배경은 알파 투명, 글자 없음. 과도한 사실적 피부 표현보다 귀여운 얼굴선과 감정 전달을 우선합니다.

- `public/art/character-sheet.webp`: 3열×2행. 윗줄은 주인공의 평상시·당황·웃음, 아랫줄 첫 칸은 전임자 선배.
- `public/art/boss-portrait-v4.webp`: 현재 팀장님. 3열×1행, 평상시·까칠함·미소. 원본 사진은 저장소에 포함하지 않음.
- `public/art/boss-sheet.webp`: 이전 캐릭터 원본 보관.
- `public/art/office-scene.webp`: 원본 저장소의 사무실 배경을 재사용.
- `public/art/city-scene.webp`: 원본 저장소의 성남 도시 배경을 엔딩에 재사용.

새 캐릭터 이미지는 imagegen으로 생성했습니다. 웹용 WebP 변환 시 배치·표정·투명도를 유지하고 파일 크기만 줄였습니다. 배경의 이동과 인물 호흡은 CSS로 처리하고, 움직임 줄이기 설정을 존중합니다.

2026-10-21: 기본 imagegen 도구로 주인공 스프라이트를 가장 중요한 그림체 기준으로, 사용자 제공 사진은 얼굴·헤어의 느슨한 참고로 생성. 지시: 주인공과 같은 손그림 선화, 단순한 코와 입, 따뜻한 셀 채색과 귀여운 비율, 성인 여성 팀장, 같은 의상과 인물 비율로 평상시/꾸중/미소를 3개 정사각형 셀에 배치, 투명 배경. 사실적인 피부·광택·3D 음영은 배제. WebP 인코딩은 해상도와 알파를 유지함.

최종 피부 톤 보정: 같은 선화·표정·의상·구도를 보존하며 얼굴·귀·목·손의 노란기를 줄이고 밝은 중성 아이보리 톤으로 조정. imagegen 편집 사용.
