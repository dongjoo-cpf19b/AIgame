# 검증 기록

2026-10-21 · Sites 이전 버전

- TypeScript 정적 검사 및 Vinext 프로덕션 빌드 성공
- 서버 통합 테스트: 실제 API 핸들러 + 격리된 메모리 SQLite 사용
- 비로그인 명단/추첨 차단, 플레이 토큰 분리, 다른 출처 요청 차단
- 서버 채점, 다섯 답변 검증, 완료 후 늦은 자동 저장으로 진행이 되돌아가는 문제 방지
- 완료 전 응모 차단, 동의 필수, 번호 형식 정리, 번호 및 세션 중복 방지
- 관리자 비밀번호 확인, HttpOnly/Secure/SameSite 쿠키, 세션 만료 및 로그아웃, 로그인 시도 제한
- 당첨자 중복 제외 추첨, 인증 후 개별 삭제, 관리 통계
- 브라우저 390×844 화면: 첫 화면, 프롤로그, 자료 탐색, 단서 수집, 메신저 전송/읽음/답장, 통화 연결/타이머/종료, 보고 정오답 반응, 새로고침 후 이어하기, 최종 채점, 엔딩, 로컬 테스트 응모 완료 확인
- 320×667 작은 휴대폰 및 데스크톱 첫 화면 배치 확인
- 관리자 로그인 화면의 브라우저 렌더링 확인. 로그인 이후 관리 기능은 서버 통합 검사로 확인했으며 실제 브라우저 인증을 통한 전체 관리 화면 검증은 하지 않음
- 기기 음성 합성 및 진동은 실제 휴대폰의 브라우저/설정에 따라 달라질 수 있음

로컬 검증 자료는 운영 데이터베이스에 포함되지 않습니다.

2026-10-21 · 모바일 가독성 개선

- 나눔고딕 400/700/800 굵기를 사이트 자체 파일로 제공하며 OFL 라이선스 포함
- 게임·관리자 UI의 작은 글씨 확대, 모바일 높이/너비별 축소 규칙도 함께 조정
- 배경 그림 위 제목·시간 안내에 어두운 받침 추가, 안내·대사·검색 결과의 명도 대비 강화
- 390×844 및 320×667 브라우저에서 검색 입력/검색 버튼/빠른 검색의 분리 확인; 작은 화면에서도 검색 폼 다음 영역과 18px 간격 확인
- 로컬 새 플레이 → 다섯 문항 보고 → 마지막 통화 → 엔딩에서 경품 안내 팝업 자동 표시 → 응모 양식 연결 확인
- 응모 팝업은 320×667 화면 안에 표시되며 닫기·나중에 참여 선택 제공. 새 응모 정보를 운영 DB에 추가하지 않음

2026-10-21 · 업무 PC 및 공문 현실감 개선

- Windows 스타일 바탕화면, 시작 메뉴, 작업표시줄, 파일 탐색기와 창 확대/복원 적용
- 계획안·결과보고·소방계획서 본문, 결재표지, 부서 협조 시행문을 각 문서 성격에 맞게 재구성
- 한글 문서 보기에서 모바일 읽기 보기와 A4 원본 크기 보기 전환 제공
- 320×667 / 390×844 및 1100×850 브라우저 화면에서 긴 파일명, 문서 본문, 결재표지 배치 확인
- 로컬 새 플레이에서 공용폴더 → 문서등록대장 → 소방계획서 → 피난동선도 탐색으로 단서 10개 모두 수집 확인

- 응모·관리자 API 및 데이터베이스 구조 변경 없음. 확인 과정은 로컬 데이터만 사용
